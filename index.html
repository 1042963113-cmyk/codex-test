PRODUCT / 作品

第五版开始，
网站有了真正的功能。

除了视觉与响应式体验，V5 加入实时 GitHub 数据、项目详情页和可分享链接，让 Portfolio 从静态展示变成可持续使用的产品。

01

实时 GitHub 数据

通过 GitHub 公共 API 读取 stars、forks、最近更新时间与默认分支，失败时自动回退。

02

独立项目详情页

新增 project.html，用完整页面介绍技术架构、迭代过程和上线链路。

03

分享与复制链接

支持原生 Web Share API；不支持时自动复制当前页面链接。
