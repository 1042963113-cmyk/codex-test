V6 FEATURES / 新功能

第一次，网站里的内容
可以被你真正管理。

V6 新增一个独立本地工作台。你可以创建、编辑、删除项目，并通过搜索和状态筛选快速整理内容。数据默认保存在当前浏览器。

01

项目 CRUD

创建、读取、编辑和删除项目，完成完整的前端数据管理闭环。

02

搜索与筛选

按名称、描述、标签搜索，并按“想法 / 开发中 / 已上线”状态过滤。

03

本地保存

使用 localStorage 保存项目，不需要账号或服务器；刷新页面后仍会保留。

04

JSON 备份

支持导出本地项目为 JSON，也支持重新导入，方便做本地备份和迁移。
