# PACKFORM T1

背包三角补强片全自动缝制工作站的概念展示网站。页面梳理现有设备路线，并提出集柔性供料、视觉定位、热压折边、数控缝制和检测收料于一体的整机方案。

## 功能

- 四类市面设备路线与采购判断
- 可交互的五工位整机方案
- 目标技术参数与完整工艺流程
- 基于班次、工时、设备数和节拍的日产能计算器
- 响应式布局、键盘可访问导航及减少动态效果支持

## 本地预览

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000`。

> 本项目为概念设计。机器的节拍、精度、适用材料和投资预算需要使用客户真实物料连续打样后确认。
